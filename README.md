# Monitor-VC

Sistema web para monitoramento operacional de salas e dispositivos de videoconferência.

## Sobre o projeto

O Monitor-VC foi desenvolvido para apoiar a análise operacional de ambientes de videoconferência, reunindo informações de dispositivos, salas, status de conexão, alarmes e indicadores técnicos em uma interface centralizada.

O objetivo do sistema é facilitar a identificação de falhas, reduzir o tempo de diagnóstico e apoiar a tomada de decisão em ambientes de suporte técnico e monitoração.

## Funcionalidades

- Monitoramento de salas e dispositivos de videoconferência
- Visualização de status operacional
- Organização de alarmes e ocorrências
- Estrutura preparada para integração com APIs
- Backend separado para tratamento de dados
- Interface web para apoio à operação técnica
